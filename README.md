# 🌍 Travel Explore

> A simple travel organizer for travel agencies

Welcome to **Travel Explore**! This application helps travel agencies manage customer trips effectively, offering a seamless way to view, add, update, and remove trip information.

---

## 🚀 Technologies Used

- **.NET Core**  
  A cross-platform framework for building modern, cloud-based applications.

- **Entity Framework**  
  An open-source ORM framework for .NET applications that supports LINQ queries, change tracking, and schema migrations.

- **WinUI 3**  
  The latest UI framework for Windows applications, providing a modern interface and great performance.

- **SQL Server**  
  A powerful relational database management system by Microsoft for storing and retrieving data.

## 🔧 Usage

Once the application is running, you can:

-   **Navigate** through the user-friendly interface to view trip details.
-   **Add** new trip entries using the "+ New travel" button.
-   **Edit** existing entries by selecting a trip and choosing the "Update" option.
-   **Delete** unnecessary trips by selecting them and clicking the "Delete" button
